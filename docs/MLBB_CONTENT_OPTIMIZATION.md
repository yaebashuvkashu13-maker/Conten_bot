# MLBB: быстрее обучать качество и уникальные нарезки

## Проблема сейчас

- Калибровка «15 роликов в час» — это **ручная разметка через Telegram**, не машинное обучение.
- Алгоритм — **правила OpenCV** (HUD, миникарта, промо, мемы), точность без ваших меток ~40%.
- n8n в проекте — **оркестратор** (триггеры, HTTP), а не тренировка модели «что такое геймплей».

## Что дало пакет 26× Chou (лучший путь)

1. Вы прислали **одного героя, только матч** — это золотой датасет.
2. Файлы копируются в `hero_datasets/chou/owner_*` и идут в **7 нарезок** без TikTok-прокси.
3. Один ответ «3, 5 — не геймплей» по **готовым нарезкам** ценнее 30 сырых TikTok.

## n8n: что реально умеет

| Возможность | Есть в n8n? | Для MLBB |
|-------------|-------------|----------|
| Обучить свою CNN «геймплей/промо» | **Нет** нативно | Только через внешний API (Roboflow, Gemini Video) |
| Fine-tune LLM (текст) | Оркестрация → OpenAI/Ollama | Не для покадрового HUD |
| Gemini / GPT анализ видео | Community node, HTTP | Дорого, медленно, не 26×/час |
| YOLO детект объектов | HTTP → Roboflow | Нужна своя разметка bbox |
| Cron + Telegram + VPS script | **Да, сильная сторона** | Оставить n8n на расписание/уведомления |

**Вывод:** n8n не ускорит «понимание геймплея»; ускорит **процесс** (загрузка → скрипт → отчёт).

## Агент (Cursor) vs n8n

| | n8n | Агент + VPS скрипты |
|--|-----|---------------------|
| Скорость итерации | Нужно вручную менять workflow | Правка `gameplay_gate.py`, деплой, 7 нарезок за один заход |
| Разметка | Нет | Пакет 26 Chou → ingest → batch за минуты |
| Стоимость | Сервер n8n + API | Уже есть VPS |

**Быстрее обучаться = меньше сырых TikTok, больше ваших пакетов «герой + только матч».**

## YouTube (без прокси)

- **Прокси для YouTube не нужен** — на VPS `yt-dlp` качает напрямую.
- **Прокси нужен для массового TikTok** (LTE/datacenter в `.video_bot.env`).
- Владелец в Telegram: ссылка `youtube.com` / **Shorts** / `youtu.be` / `/live` (или `/yt <url>`) → бот качает → `/make`.
- `/ping` — поле `youtube=да` и версия `2026-06-06-youtube-shorts` после деплоя.
- Опционально в `/root/.video_bot.env`: `YOUTUBE_DEFAULT_HERO=chou` — копия в `hero_datasets/chou/`.
- Проверка: `python3 /usr/local/bin/youtube_health_check.py`
- CLI: `python3 /usr/local/bin/youtube_download.py 'https://youtu.be/...' --out /root/datasets/youtube/inbox`

### Длинные VOD (2–3 часа)

- Скачивание: до **4 ч** (`YOUTUBE_DOWNLOAD_TIMEOUT=14400`)
- `/make`: до **4 ч** на анализ (`SMART_MAKE_TIMEOUT_MAX_SEC=14400`)
- С 20+ минут включается **быстрый проход** по всему ролику; до **20** лучших сегментов на источник, в монтаж — **3–4** (~33–57 с)
- Один длинный VOD = **одна** нарезка за `/make` (для нескольких нарезок — несколько `/make` или пакет героя)

## Команды на VPS

```bash

# Загрузки из Telegram → датасет героя
python3 /usr/local/bin/ingest_pending_to_hero.py <CHAT_ID> chou

# 7 нарезок
set -a; source /root/.video_bot.env; set +a
HERO_ID=chou MONTAGE_COUNT=7 STRICT_GAMEPLAY=0 \
  python3 /usr/local/bin/build_hero_montage_batch.py
```
